# 👨‍💻 Lucas Rodrigues

### Engenheiro de software · Sistemas fullstack · Backend com regras de negócio

Desenvolvedor fullstack focado em projetar e construir sistemas que resolvem problemas reais — da definição das regras até a entrega em produção. Trabalho decisões técnicas, arquitetura e consistência de dados, não apenas a camada de interface.



---

## Especialidades

- Arquitetura de sistemas e definição de fronteiras entre camadas
- Backend com regras de negócio e fluxos consistentes
- Modelagem de banco de dados (PostgreSQL / SQL)
- Integrações entre serviços, APIs e superfícies web
- Infraestrutura básica: VPS, processo, proxy e CDN

## Forma de trabalho

1. **Entendimento do problema** — contexto de negócio, restrições e resultado esperado
2. **Definição das regras** — o que o sistema pode e não pode fazer
3. **Modelagem** — dados, fluxos e responsabilidades
4. **Arquitetura** — estrutura da solução e fronteiras entre camadas
5. **Implementação com IA** — aceleração com revisão técnica sobre o que entra em produção
6. **Deploy** — publicação e operação (VPS, PM2, Cloudflare)
